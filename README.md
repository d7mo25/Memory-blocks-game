# Memory Blocks Game 🧠

A web-based memory matching game built with HTML, CSS, and JavaScript. Flip the blocks, match the technology icons, and try to finish with as few wrong tries as possible!

## 🎮 Play It Live

👉 [https://d7mo25.github.io/Memory-blocks-game/](https://d7mo25.github.io/Memory-blocks-game/)

## Features

- Flip-to-match gameplay with tech stack icons (Angular, Vue.js, CSS3, GitHub, Gulp.js, HTML5, Jest, MongoDB, Python, React)
- Wrong-tries counter
- Sound effects for success and failure

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Running Locally

1. Clone the repository
2. Navigate into the `Memory-Blocks-Game` folder
3. Open `index.html` in your browser

## Deployment

This project is automatically deployed to GitHub Pages via GitHub Actions whenever changes are pushed to the `main` branch.
